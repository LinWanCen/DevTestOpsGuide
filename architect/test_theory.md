# 测试理论

## 静态测试
需求、设计、结构分析、流程图分析

2021下考题：是指被测试程序不在机器上运行，而采用人工监测和计算机辅助分析的手段对程序进行监测

## 黑盒测试（2021下考题：也称为功能测试）
依据 SRS 软件需求规格说明 Software Requirements Specification
- 边界值分析
- 因果图
- 判定表/判定树：多个逻辑条件取值组合所构成的负载情况下，分别要执行哪些不同的动作（2022下考题）
- 等价类划分法：有效/无效 （符合/不符合《需求规格说明书》）
- 正交实验法

## 白盒测试
- 逻辑覆盖
- 语句覆盖
- 判定覆盖 分支覆盖
- 条件覆盖
- 判定/条件覆盖
- 条件组合覆盖
- 路径覆盖 （2022下考题：测试强度最高的）
- 循环覆盖
- 基本路径测试

## 灰盒测试（输入输出与逻辑）

## 测试阶段
- 单元测试
- 集成测试
- 回归测试：软件原有的、正确的功能、性能和其他规定的要求的不损害性（2022下考题）
- 冒烟测试
- 系统测试：功能、性能、健壮性、安装或反安装、用户界面、压力、可靠性及安全性
  - （2024下考题：系统测试是为了发现需求分析出现的错误）
- 验收测试：针对SRS，在交付前以用户为主进行的测试。
- Alpha 测试：用户 在 开发环境
- Beta  测试：用户 在 实际使用环境

### Web 服务器测试
- 基准性能测试
- 压力测试
- 可靠性测试 （2021下考题）

性能指标：（2021下考题：不包括链接正确跳转）
- 连接速度
- 最大并发连接数
- 响应延迟
- 吞吐量
