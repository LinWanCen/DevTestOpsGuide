# 数据库架构《数据库系统概论

### 数据库模式
- 外模式 用户不同
- 概念模式 由 DBA 设计（全局模式）
- 内模式 物理存储 如索引用 B+tree 还是 Hash、引擎等（2022下考题：加索引改变了什么模式）

### 函数依赖
X -> Y 表示 X 的值唯一确定 Y 的值
F 是显式定义的函数依赖集合
F⁺是包含推导的，所有被 F 蕴含的函数依赖集合
F = {A->B, B->C} F⁺ 还包含 A->C, A->AB, B-BC 等

- 自反律：Y ⊆ X 则 Y -> X 例 X = {A, B} Y = {A}
- 增广律：X -> Y 且 Z ⊆ Y 则 XZ -> YZ （增了Z）
- 传递律：X -> Y 且 Y -> Z 则 X -> Z
- 合并规则：X -> Y 且 X -> Z 则 X -> YZ
- 伪传递规则：X -> Y 且 WY -> Z 则 XW -> Z
- 分解规则：X -> Y 且 Z ⊆ Y 则 X -> Z （2022下考题）

### 代数运算

- select π 列 属性
- where  σ 行 元组 去重！（2021下考题：自然连接后属性列数和元组个数）
- join   ⋈
- union  ∪
- intersect / inner join ∩
- except / left join -
- cross join / 笛卡尔积, ⨯
