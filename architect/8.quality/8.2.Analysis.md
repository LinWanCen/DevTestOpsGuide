## 系统架构评估 Architecture Analysis

### 8.2.1 系统架构评估中的重要概念
- 敏感点 Sensitivity Point 搞清楚如何实现质量目标时应注意什么（2021下考题）
- 权衡点 Tradeoff Point 是多个质量属性的敏感点

2021/2022下考题：改变加密级别可能会对安全性和性能产生非常重要的影响，该设计决策是一个权衡点

### 8.2.2 系统架构评估方法

#### SAAM 基于场景的架构评估
Scenarios-based Architecture Analysis Method

针对最终架构而非详细设计进行评估。
SAAM的评估过程包括:场景开发、架构描述、单场景评估、场景交互评估和总体评估。

#### ATAM 架构权衡分析方法
Architecture Tradeoff Analysis Method

- 评估方法设计之初：性能、可用性、安全性、可修改性，也就是利益相关者最为关心的，其中可测试性不在初步评估
- 效用树 Utilit Ytree 树根 -> 【质量属性】 -> 属性【分类】 -> 质量属性场景 （2022下考题 2024下考题）
  修剪保留重要场景（通常不超过50个）
  优先级 H/M/L + 难易度 H/M/L
- 2024下考题：选 ATAM
- 2024上考题：案例填效用树
