## 8.1 软件系统质量属性

### 8.1.1 质量属性概念
- 开发期
  - 易理解性
    易用性：（2022下考题：想要学习系统特性、有效使用系统、使错误的影响最低、适配系统、对系统满意属于易用性质量属性场景的刺激）
  - 可扩展性
  - 可重用性
  - 可测试性
  - 可维护性：（2022下考题：是当需要修改缺陷、增加功能、提高质量属性时，定位修改点并实施修改的难易程度）
  - 可移植性：将软件系统从一个运行环境转移到另一个不同的运行环境的难易程度。
- 运行期
  - 性能： 衡量系统的响应能力和处理能力，通常通过单位时间内处理事务的数量或系统完成某个事务处理所需的时间来评估。
    - 2021下考题：（性能）是指系统的响应能力，即要经过多长时间才能对某个事件做出响应，或者在某段时间内系统所能处理的事件的（个数）
  - 安全性： 关注系统对抗安全威胁的能力，包括机密性、完整性、不可否认性和可控性等安全特性。
    - 2021下考题：（机密性）保证信息不泄露给未授权的用户、实体或过程；（完整性）保证信息的完整和准确，防止信息被篡改。
  - 可伸缩性：（2022下考题：当用户数和数据量增加时，软件系统维持高服务质量的能力）
  - 互操作性： 关注软件系统与其他系统或环境相互作用的能力，需要设计精心的软件入口以支持与其他编程语言编写的系统的交互。
  - 可靠性： 关注系统在面对错误或异常情况时的能力，包括容错性和健壮性，使用平均失效等待时间和平均失效间隔时间等指标来衡量。
  - 可用性： 衡量系统正常运行的时间比例，通常通过计算两次故障之间的时间长度或系统从故障中恢复正常的速度来评估。（2021下考题：30秒恢复体现）
  - 鲁棒性： 也称健壮性或容错性

### 故障时间 9.1.2
- 故障间隔 MTBF = 无故障 MTTF + 修复时间 MTTR （重点 BF = TF + TR）
- 修复时间 MTTR = 检测 MTTD + 修复活动 MTTA
- 可用性 Availability = MTTF / MTBF = 无故障 MTTF / (无故障 MTTF + 修复 MTTR) = MTTF / (MTTF + MTTD + MTTA)
- MTBF ≈ MTBR

- MTBF（Mean Time Between Failures）：平均故障间隔时间，是系统在两个故障之间的平均正常运行时间。
  - MTTF（Mean Time to Failure）    ：平均失效等待时间，无故障时间，越长越好
  - MTTR（Mean Time to Repair）     ：平均修复时间，是修复故障所需的平均时间。
    - MTTD（Mean Time to Detect）       ：平均故障检测时间，是检测到故障所需的平均时间。
    - MTTA（Mean Time To Act）          ：平均修复活动时间，
- MTBR（Mean Time Between Repairs） ：平均修复间隔时间，是修复后到再次发生故障的平均时间。
